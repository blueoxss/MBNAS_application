## Evidence (WP-1C, CPU only, runtime/venv python 3.10.22)

- Installed parser source: `hashlib.sha256(inspect.getsource(tasks.parse_model).encode())` = `7da6bb14…5f6d` (equals the static value of ETRI_RUNTIME_SCOPE §4.2).
- Static proof: `parse_model_8_4_173.verify_static_copy()` → `equivalent: true`, `base_modules: 37`, `repeat_modules: 17`; three mutated copies of the installed source were reported as not equivalent.
- Dynamic parity (scratch script, not part of the packages): the snapshot's original `mixed_blocks.py` (loaded by file path under the name `yolo_ga_runtime.mixed_blocks`, package `__init__` not executed, original AST patch + `exec`) and the vendored operators built yolo11n and yolo26n `native` / `cnn_backbone` / `transformer_backbone` (from the original `make_mixed_seed_variants`) plus a NASGlobalTransformer/NASWindowTransformer variant with n=2 repeats, as `DetectionModel` on CPU.
